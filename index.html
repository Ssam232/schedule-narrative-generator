    Privacy and how it works

    Your schedule files never leave your device. The generator runs entirely in your web browser: it reads your P6 exports, analyses them and writes the report on your own computer. Nothing is uploaded, and no AI service or person sees your data.

    What happens to your files

    • When you add an XER file, your browser reads it into this page’s memory. It is not uploaded or copied anywhere.
    • Removing a file, reloading or closing the page discards it.
    • Only what you choose to take leaves the page: the Word or Markdown file you download, or text you copy.

    How the engine works

    • It reads the tables in each export: activities, relationships, calendars, WBS, activity codes, resources and costs.
    • It matches the versions by Activity ID and compares them to find progress, slippage, changes and earned value.
    • It works out the critical path, float paths and target date risk, plus the Monte Carlo analysis if you turn it on, with fixed calculation rules. The same files and settings always give the same report.
    • It writes the report from built-in sentence templates and leaves highlighted blanks for you to complete.

    What the page remembers

    Your settings, such as the Prepared by name, light or dark mode, the target dates and end activity you pick, and your element keywords, are saved in this browser on this device so they are ready next time. The contents of your files are never saved.

    Safeguards

    • The page is locked down: your browser blocks it from connecting to any server, so even a damaged or malicious file could not send data anywhere.
    • Everything it needs is built in. There are no analytics, trackers, cookies, ads, or outside scripts or fonts.
    • Text from your files is always shown as plain text and never run as code.
    • The source code is public, so anyone can check how it works: github.com/Ssam232/schedule-narrative-generator.

    Where the page runs

    • Online: Streamlit Community Cloud delivers the page. Like any web host it can see that a visit happened, such as your IP address and browser, but it never receives your files or reports. Streamlit’s usage statistics are turned off for this app.
    • Offline copy: the HTML file works without an internet connection, so it involves no host at all. It is the most private way to use the generator.
    • In Claude: the page runs in a private, locked-down frame. Saving the Word or Markdown file passes it to the Claude app so it can save it for you.

    Things only you control

    • Browser extensions and anyone using your computer can see what is on your screen. On a shared computer, clear saved settings when you finish.
    • Downloaded reports contain your project information, so store and share them as you would the schedule itself.
